# TS-035D6-P offline design evidence

Base: `335663fcddf5bfc595369c6a8f68b584a9165e0f`, accepted D5.
See [dispatch design](../../script-assignment-target-dispatch.md).

This directory contains proposals and bounded current Node probes only. No
production/real old-test change, full build, invalid numeric guest-body execution, native run,
admission or publication is claimed. Native labels describe future obligations.
Inherited counts remain 212 guest records per host, 68 gates and 60 blocked.

Run from the repository root:

```powershell
node typescript/docs/validation/ts-035d6-p/verify.mjs
node typescript/docs/validation/ts-035d6-p/check.mjs
```

`freeze.mjs` captures current accepted D5 APIs, full literals, protected history
and source consumers. `probe.mjs` uses only the already built accepted Node D5
audit driver in both input orders and checks inherited preparation expectations.
`proposals.mjs` renders complete old files; `production-proposal.mjs` renders five
editorial production files without loading them. `controls.mjs` creates literal
future state/metadata controls and current profile-only preparation probes.
`make-wire.mjs` renders the independent both-mode fixture runner; `wire.mjs`
uses the actual current Node serializer and both current decoders. Future code
is never loaded. `occurrence-probe.mjs` validates all 98 future-control requests
and 366 semantic requests through actual current `observeScripts`; only harmless
prefixes and the valid ready reference control execute. It checks 2088 malformed
occurrence neighbors and reproduces the 24 original bad-prefix failures retained
under `original-occurrence-contract/`. `check.mjs` records results under this
directory only.

Key evidence:

- 898 full old-file proposals: four exact migrations, 894 identities; Git and
  checkout bytes, blob/SHA-256 hashes, whole-file verifier. All 5123 protected
  tracked files include original D5-P, D5 records and C++.
- 102 full D5 audit/preparation rows, 56 full blocked audit oracles; 366 complete
  child contexts; 360 inherited D2/D3/D4 preparation literals remain unchanged.
- 256 wire rows: 192 existing-code controls accepted, 64 numeric-code controls
  rejected by current decoders; 77184 malformed checks. Numeric malformed tests
  currently use the disclosed block-code surrogate. Future both-host producer
  bytes remain required.
- Eight profile literals, 24 prefix children, 12 history/no-effects cases,
  36 metadata/source cases, 72 budget request/child literals, two ready controls
  and 512 full producer-oracle mutations. History assertions use the actual
  detached inspection API; the corrected initial draft is retained separately.
- `source-consumers.json` inventories 102 matching source files with exact lines,
  including historical scripts and ignored host adapter files.

Original D5-P history is untouched. Historical generators/default wire modes and
milestone preservation proofs are retained as history, not rewritten to claim
D6. `verify.mjs --applied` is reserved for a later approved implementation and
checks exact old-test results; it does not waive future production or native
verification. Failures and uncertainties are retained in `failures.json` and
any `failed-check-*` or `probe-failure.json` files.
