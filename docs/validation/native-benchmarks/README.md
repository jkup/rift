# Saved native benchmarks

[native-comparison.txt](native-comparison.txt) summarizes the 2026-11-19 measurements. The three JSON files retain final samples, preflight failures, hashes and build provenance without modification. They compare scriptc-compiled Rift with the retired implementation.

These are historical results from one machine, not a general performance claim. Paths and reproduction commands in the captured reports describe the checkout at measurement time; the retired engine and its build scripts are no longer included.

[index.js](index.js) is a standalone JavaScript workload.
