# String at and trim aliases

String.prototype.at converts the receiver before its relative index and returns
one UTF-16 code unit, or undefined outside the bounds. A surrogate pair is not
combined. trimLeft and trimRight initially reference the exact trimStart and
trimEnd function objects; subsequent assignment to either property is independent.

The isolated draft passes 692 Node guest cases, focused native execution with
11,760 statically compiled statements and zero dynamic statements, and both
bootstrap and formatting inventories. Combined integration remains pending.

References: [ECMAScript 2025 at](https://262.ecma-international.org/16.0/#sec-string.prototype.at)
and [Annex B trimLeft](https://262.ecma-international.org/16.0/#sec-string.prototype.trimleft).
Legacy-profile registration is unchanged.
