# Labelled Script control flow

TS-147 adds labels and labelled break/continue to structural Script parsing and execution. The legacy parser remains unchanged. Labelled function declarations and direct lexical declarations remain unsupported, and break/continue retain the existing explicit-semicolon boundary. A line terminator prevents reading a target identifier; general automatic semicolon insertion is separate.

The parser keeps active label names and whether each label directly identifies an iteration statement. Lookahead through a chain of labels gives every label in that chain the same iteration classification. Ordinary function, method and arrow bodies start with empty label scopes. Duplicate active labels, unknown targets and continue to non-iteration labels are rejected before execution. Labels do not introduce lexical scopes or bindings.

Break and continue completions carry an optional string target. UpdateEmpty preserves it while supplying a previous statement value. Labelled evaluation passes its accumulated names only to the directly labelled item, consumes a matching break, and otherwise propagates the completion. Loops consume untargeted breaks and matching continues. Blocks, conditionals and other intervening statements do not pass their label sets to nested loops.

For-of keeps its iterator open for a continue targeting the same loop. Breaks, returns and continues to outer loops close it before propagation; existing throw precedence and fatal-resource behavior remain in the iterator helpers. Loop updates, per-iteration lexical environments and finally completion replacement follow their existing paths.
