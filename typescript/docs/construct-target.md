# Distinct constructor targets

TS-157 separates the constructor being invoked from newTarget, which controls instance prototype selection and the function environment's new.target. Bound constructors replace newTarget with their target only when the supplied newTarget is that bound function. Script and builtin constructors share this path; the builtin permit checks callee and newTarget independently. Ordinary calls continue to have undefined new.target.

Reflect.construct is the bounded public entry point. It validates the target and any explicitly supplied newTarget before reading the array-like argument list, then reads length and indexed values in order under the execution budget. Explicit undefined differs from an omitted third argument. Reflect is an ordinary Script global with the standard tag; other Reflect methods, Proxy and class inheritance remain separate work.

Array, boxed primitives, errors and collections retain their internal storage while allocating from the requested prototype. Object ignores its value argument when newTarget differs from Object. Function converts and parses the requested source before prototype lookup; generated code retains the Function constructor's Realm and global environment. Symbol intentionally remains a constructor whose construction body throws, so argument-list evaluation still precedes that rejection.

The Script context provides an optional construction callback alongside call and tick. Legacy and host-only contexts need not provide it. The callback is the owning engine's ordinary guarded construction path; captured contexts cannot operate after their Script frame ends. Its field declaration must match the writable context view because of the retained [native compiler projection probe](validation/ts-157/README.md).
