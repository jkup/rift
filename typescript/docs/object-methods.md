# Object literal methods and accessors

TS-130 adds fixed identifier, string and numeric keys for Script object methods and getters/setters. Object properties now carry their key, definition kind and expression together rather than in parallel arrays. Both syntax visitors traverse the value expression. Functions retain their source span, lexical environment and inherited/body-directive strictness; object methods are not automatically strict.

Method source metadata selects callable-only allocation: no constructor slot or own prototype property. Ordinary function expressions keep their constructor behavior. Accessor names include the get/set prefix. Definitions use partial accessor descriptors, preserving the opposite accessor when paired and allowing ordinary data/accessor replacement through existing descriptor rules. Method and accessor names __proto__ are ordinary own properties; prototype-setting colon syntax remains unsupported.

References consulted 2026-11-09: [DefineMethod and MethodDefinitionEvaluation](https://tc39.es/ecma262/multipage/ecmascript-language-functions-and-classes.html#sec-runtime-semantics-methoddefinitionevaluation), engine262 [DefineMethod](https://github.com/engine262/engine262/blob/main/src/runtime-semantics/DefineMethod.mts) and [MethodDefinitionEvaluation](https://github.com/engine262/engine262/blob/main/src/runtime-semantics/MethodDefinitionEvaluation.mts). Rift uses the same callable versus constructor distinction and partial accessor descriptors. Home-object/super behavior is deferred because super syntax is rejected before execution; no source is delegated to a host engine.

Computed names, shorthand data properties, object spread, classes, async/generator methods, rest/default/destructuring parameters, arguments objects and trailing object commas remain outside this slice. Invalid accessor arity and duplicate method parameters are rejected conservatively as unsupported syntax, not newly admitted Test262 early-error classifications. Legacy parsing still rejects methods/accessors.

Focused Node/native tests pass, with 7499/7499 statements static. Full acceptance is pending. A test initially assumed arguments-object support; that unsupported feature was removed from the test scope before native validation. Coverage includes descriptor pairing/replacement, names/lengths, source strings, non-constructability, this, closures, inherited accessors, strictness, captured Realms and bounded recursion.
