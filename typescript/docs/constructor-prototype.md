# Constructor prototype selection

TS-156 centralizes prototype lookup for Script function construction and the existing Array, Boolean, Number, String, Error, Map and Set constructors. The helper performs one ordinary prototype Get with the constructor as receiver. An object result is used directly; any primitive result selects the requested intrinsic from the supplied constructor's Realm. Current bound callable metadata retains its target's Realm. Proxies remain unsupported.

Each caller keeps its allocation and coercion order. Number and String still convert before lookup; Error looks up before converting its message. Map and Set now explicitly use the shared lookup of their fixed intrinsic prototype properties. Object's equal-target argument preservation and Function's source preparation remain separate; this change does not yet pass distinct newTarget values into builtin construction or admit Reflect.construct, extends or super.

Tests use a trusted test-only builtin to exercise the helper through real Script execution. They cover every fallback intrinsic across two Realms, nested bound constructors, getter receiver identity and single access, object versus primitive results, exact thrown-value propagation and fatal getter budgets. Existing constructor tests retain their original sources and expected traces. Focused Node/native coverage is 9343/9343 static, with zero dynamic operations; full canonical acceptance is pending.

Reviewed [ECMAScript 2025 GetPrototypeFromConstructor](https://262.ecma-international.org/16.0/#sec-getprototypefromconstructor) and engine262 [objects.mts](https://github.com/engine262/engine262/blob/18cdeb03c363eb31d775648a0d070bdc8a26ced1/src/abstract-ops/objects.mts) and [object-operations.mts](https://github.com/engine262/engine262/blob/18cdeb03c363eb31d775648a0d070bdc8a26ced1/src/abstract-ops/object-operations.mts), pinned at 18cdeb03c363eb31d775648a0d070bdc8a26ced1. The fallback Realm comes from the constructor, independently of the current execution Realm. The Symbol constructor's rejecting construct slot is intentional under section 20.4.1 and is preserved.
