# Duplicate simple parameters

TS-154 admits repeated identifier parameters in bounded sloppy ordinary functions. Arrows, methods, strict functions and non-simple parameter lists retain their rejection boundaries. The ordinary legacy parser remains unchanged. Strict duplicate detection moves from the token parser to scope analysis, where inherited and body-directive strictness are known; only the rejection-only parameter audit may bypass this detection. Supported sloppy duplicates no longer veto an otherwise certified strict duplicate elsewhere.

Function instantiation creates one binding per name. With duplicates it initializes those bindings to undefined, then assigns argument values in formal order, including missing arguments. Mapped arguments links only the last occurrence of each formal name. That occurrence is chosen before considering the number of actual arguments: f(a,a) called with one argument leaves index zero unlinked. Existing descriptor/delete behavior disconnects a mapped index as before. Keep argument objects in their function's Realm.

References reviewed before implementation: [ECMAScript 2025 FunctionDeclarationInstantiation](https://262.ecma-international.org/16.0/#sec-functiondeclarationinstantiation), [CreateMappedArgumentsObject](https://262.ecma-international.org/16.0/#sec-createmappedargumentsobject), and [engine262 FunctionDeclarationInstantiation.mts](https://github.com/engine262/engine262/blob/18cdeb03c363eb31d775648a0d070bdc8a26ced1/src/runtime-semantics/FunctionDeclarationInstantiation.mts), pinned at 18cdeb03c363eb31d775648a0d070bdc8a26ced1. The implementation reuses Rift's binding cells and completion records.

Draft tests cover missing actuals, aliasing in both directions, delete/accessor/nonwritable descriptors, closures, hoisted declarations, eval/Function, strict rejection, unsupported-context audit vetoes, defining-Realm allocation and fatal budgets. Four historical drivers retain their original source strings with explicit updated admissions; inherited strictness still rejects duplicates. The original scoping-redeclaration-test.js subsequently reaches the separate Annex B catch-var restriction. No corpus completion is claimed at this boundary.

A reduced scriptc temporary-result projection failure and the named-local variant are retained in docs/validation/ts-154. The final collector returns its strict candidate array directly and retains it before indexing. Canonical integration and acceptance are pending.
